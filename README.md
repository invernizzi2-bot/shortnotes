# Collection of Notes and Documents

This repository contains a set of PDF documents and an `index.html` page
that serves as an entry point or overview of the collection.

## Contents

- Several PDF documents, each covering a specific topic
- [`index.html`](index.html) — index or presentation page for the collection
- Public site: https://invernizzi2-bot.github.io/shortnotes/

## Structure

All PDF files are self‑contained and can be read independently.
The `index.html` page provides a simple navigational overview.
The public site mirrors the same structure for convenient online access.
